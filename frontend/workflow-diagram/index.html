SAATHI · System Architecture

How a case actually moves through the system

Text Analysis and Acoustic Analysis run at the same time on the same interaction. The Safety Engine runs independently of both — reading the transcript they produce, plus a few direct safety questions — and can send a case straight to a human without waiting for either score.
